# IntelliCase Pro Roadmap

## Current MVP
- Dashboard and KPIs
- Case management
- Clients
- Evidence register
- Time and expenses
- Invoices overview
- Reports page
- Calendar
- Settings / placeholder admin

## Phase 2
- ASP.NET Identity
- User roles: Admin, Investigator, Billing, Read-only
- File upload and secure download
- Chain of custody timeline per evidence item
- Task notifications
- Saved filters
- Search across cases, evidence, and notes

## Phase 3
- Offline sync for field work
- Geospatial mapping
- Third-party integrations
- Report templates with PDF export
- Agency branding / white-label options
- Multi-agency tenancy
